# 三月七小助手（星穹铁道）

- 仓库：moesnow/March7thAssistant；Windows 用 `March7thAssistant_full.zip` 完整包（自带 Python 运行环境）。
- 命令行入口：`March7th Assistant.exe <任务名>`；`-l` 列出任务，`--list-workflows` 列出流程，`--workflow-name <名称>` 运行流程。
- 操作 PC 版游戏窗口，会占用鼠标键盘，不能和其他前台脚本同时运行。
- 配置文件：`config.yaml`（更新时会被带到新版本）。

具体任务的启动参数在 M2 由分析器根据 `--help` 输出补全。
