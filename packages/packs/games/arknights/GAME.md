# 明日方舟（官服）

- 活动时间以 PRTS 为准：先 `game_sites_refresh`（game=arknights），不用自己去网页上找。PRTS 打不开时再用 `web_fetch` 看官网公告 https://ak.hypergryph.com/news 。
- 游戏在**模拟器**里（`screen_capture` 用 target=emulator）。MAA 跑日常时会占用模拟器：先 `script_runs` 看有没有 MAA 正在运行，有就等它结束再看，不要打断。

## 进到活动页（只看，不花东西）

1. 截图。不在主界面就点左上角的返回或「首页」图标回到主界面；有公告或签到弹窗先关掉（右上角的 ×）。
2. 主界面左下角是活动横幅（会轮播）；点横幅进对应的活动页。也可以点右侧「终端」，在顶部的页签里找到当前活动。
3. 活动页上读：活动名、「剩余 X 天 X 小时」或结束日期、关卡是否都已通关（关卡上有完成标记）。
4. 「活动商店」：读代币余额，以及还有哪些商品没换完（显示剩余数量的格子）。只看，**不要点兑换**。
5. 主界面「任务」→ 日常 / 周常：读未完成的任务数量。

读完按返回回到主界面。

## 记录

`game_record`（game=arknights）每个活动一条：名称写活动名本身（如「昨日海」，不用写 SideStory 前缀）；剩余时间照界面原文填 `remaining`；没完成的写进 `todo`，例如「活动商店还剩 3 项没换」「EX 关卡未通关」。
